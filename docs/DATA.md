# 数据约定

## 强度与位深

所有运行入口使用 `polarized_csi/io.py`。8 位灰度除以255，16 位灰度除以65535，浮点图和 NPY 默认已经在[0,1]。原始10/12位数据若存储在16位容器中，使用同一个 `--white-level`，例如12位传感器可按实际标定指定4095。

不按每张图的最大最小值单独归一化，不把RGB图直接当作标定后的强度。彩色相机需先明确线性响应、色彩通道和灰度转换方案。相机的黑电平、暗场、饱和、曝光漂移和非线性响应仍需实验校正；脚本不会自动完成这些光学校准。

NPY输入默认保持尺度，只接受有限、非空二维[0,1]测量；未归一化的原始NPY可显式指定白电平。NaN/Inf、负强度、超范围输入和标签空间尺寸错误均拒绝。

## 五角度标签

同一对象命名为 `object01_0.tif`、`object01_22.5.tif`、`object01_45.tif`、`object01_67.5.tif`、`object01_90.tif`。同一stem若同时出现多种扩展名会报错，避免默默选错。也可用规范化的二维NPY捕获图。

当前理想约定：QWP是理想四分之一波片，LP透振方向固定45°，QWP角度取0°、22.5°、45°、67.5°、90°，沿用现有S3符号约定。

```text
S0 = I0 + I90
S3 = I0 - I90
S1 = 2*(I22.5 - I67.5) - sqrt(2)*S3
S2 = 2*I45 - S0
```

该代数关系在指定理想测量模型下可检查，不代表实际元件的快轴、角度零点和圆偏振手性已标定。用已知线偏振及圆偏振状态确认符号和响应。标签保存为float32 `(H,W,4)`，通道顺序固定S0、S1、S2、S3；S1至S3可以为负，输出不能简单截断到正数。

`S0 >= 0`且`sqrt(S1²+S2²+S3²) <= S0`只适用于共同物理尺度的原始Stokes。统计变换、测量噪声及系统误差都需要先说明。程序报告违规率，不自动把标签投影成“正确”值。

## 配对与划分

```text
train/c/object01.tif  <-> train/s/object01.npy
val/c/object02.tif    <-> val/s/object02.npy
 test/c/object03.tif  <-> test/s/object03.npy
```

同stem一一对应，重复stem或任一侧漏项会报错。每个批次内尺寸必须一致；当前不自动裁剪、配准或缩放。五角度图和压缩图要同视场、同ROI和可比较的曝光尺度。

训练、验证、测试按对象或独立采集场次分开。程序能检查路径重叠，无法仅凭文件名判断两张图是否来自同一对象；复制文件或换名不会自动变成独立样本。使用 [采集清单](../experiments/capture_manifest.csv) 记录样本关系。

## 模型与评价

模型权重 `.pt` 保持原state_dict格式，旁边的 `.pt.json` 记录超参、种子、版本、数据哈希、训练历史、所选轮数和数据审计。旧权重来源未知时，重新训练并独立命名。TensorFlow预处理尺度修复后，旧TF权重必须重新训练。

PSNR/SSIM需要显式定义强度动态范围。`evaluate.py --data-range target`为每通道真值的max-min，近常数通道回退1.0；固定正数则所有通道使用该值。不同定义不能直接比较。近零MSE时99 dB是有限数值标记，不能解释为实测无限精度。

训练损失、验证损失和最终测试指标用途不同。不能把训练集重建指标当作测试泛化指标。
