# 实验路线

目标是建立一条可以逐步核对的链路：已知偏振状态 → 实际测量 → 标签 → 压缩图 → 基线重建 → 独立评价。每一步保留原始文件和参数，上一阶段不通过时先定位原因。

## 第一步 软件自检

按README安装，运行测试与 `scripts/smoke_test.py`。只确认程序可执行，不写真实精度结论。命令、日志、JSON和数据来源放在同一个运行目录。

## 第二步 测量校验

先选一个已知偏振状态样本，记录实际器件、QWP快轴、LP角度零点、相机曝光/增益/位深、光源与采集日期。固定视场和曝光采五角度图，保存未处理原图，记录暗场、饱和与稳定性。

计算四通道标签，检查空间对齐、强度尺度和物理约束。将参数的符号与趋势同已知状态比较。接着换已知线偏振方向与圆偏振状态，排查角度、手性、波片延迟量和相机响应。当前软件不替代这一步。

交付物：原图、采集清单、校准说明、标签及其JSON。验收依据是已知状态的响应一致性与误差分析，不先指定一个缺乏实验依据的PSNR阈值。

## 第三步 配对数据

对同一对象，在与五角度真值可比较的条件下另采独立压缩图，记录编码角、曝光、ROI和配准方法。每一对都能追溯到原始捕获，禁止用标签本身或测试真值构造“实验输入”。

按对象或独立采集场次划分训练、验证、测试，保留清单，不在看完测试成绩后反复调整划分。扩充对象与偏振状态的覆盖范围，避免仅以同一对象相邻图像说明泛化。

## 第四步 基线重建

先使用现有796参数仿射模型，固定种子，记录训练与验证曲线。选择验证损失最佳权重，在从未参与训练和模型选择的测试对象上评价。

保存每通道真值、预测、误差以及强度范围；同时检查物理约束。可以加简单的常数预测或线性回归作对照，判断模型是否学到超出数据均值的关系。模型没有恢复信息的普遍保证，需要报告适用样本范围。

## 第五步 决定改进方向

如果标签不稳定，先处理采集和标定；如果训练也无法拟合，检查尺度、配对、学习率和模型容量；如果只在训练集表现好，检查数据量、分布及划分泄漏。依据失败证据再决定是否增加非线性、物理约束或更多独立测量。

成本、推理速度和角度鲁棒性分别设独立实验记录。报告只引用可追溯到数据、模型和配置的结果。
