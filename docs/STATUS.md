## 当前数据能说明什么

仓库包含 8 对 32×40 的示例。按未变换、共用强度尺度的原始 Stokes 参数解释，有 8929 / 10240 个像素违反理想物理约束，比例 87.197%。原始采集条件、生成过程及是否经过通道变换均未核实。因此保留示例，但只用于展示读写和软件运行。

5. 如需报告成本、速度、编码角度鲁棒性，应分别提供器件清单、计时条件和对照实验。

## 物理边界

单像素一次强度测量通常只给出四个 Stokes 分量的一个线性组合。对任意未知场景，它没有四个独立方程，不能保证唯一恢复。计算重建依赖训练分布、空间结构或其他额外先验；需要明确其适用范围。

当前模型无激活函数，整体属于仿射映射。保留它作为可解释基线，不擅自换成一个更复杂但尚未验证的新网络。报告中不得再描述为“约200参数、ReLU的非线性解码器”。

下一步优先级：已知状态样本的五角度测量校验 → 建立真实配对数据 → 基线训练和独立测试 → 再研究网络与硬件改进。
